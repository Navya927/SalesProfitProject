# Sales Profit Prediction Project

## Objective
Analyze retail sales data and predict profit using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Features
- Data Cleaning
- Exploratory Data Analysis
- Data Visualization
- Profit Prediction

## Dataset
Sample Superstore Dataset

## Machine Learning Model
Random Forest Regressor

## Author
Navya

### Findings

- Technology category generated the highest sales.
- Some products contribute significantly more revenue than others.
- Sales vary over time and show monthly trends.
- Profit is influenced by Sales, Quantity, and Discount.
- Random Forest model successfully predicts profit.
